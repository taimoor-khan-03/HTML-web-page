# DevX Landing Page 🚀

A simple and beginner-friendly responsive landing page built using HTML, CSS, and JavaScript.

## ✨ Features
- Responsive Navbar (Mobile Friendly)
- Modern Hero Section
- Features Section (Cards UI)
- Clean Footer
- Smooth UI & Hover Effects

## 🛠 Tech Stack
- HTML5
- CSS

## 🎯 Purpose
This project is created to help beginners understand how to build a basic landing page and improve their frontend skills.
